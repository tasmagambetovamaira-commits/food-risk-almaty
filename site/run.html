Запустить самому

English summary. clone the repository, create a virtual environment, install requirements, run make update to rebuild everything from raw data to the site, and make serve to view it locally.

1. Что нужно

Python 3.11+, git, make (на macOS: xcode-select --install). Интернет не нужен — все исходные данные лежат в репозитории.

2. Собрать всё одной командой

git clone https://github.com/tasmagambetovamaira-commits/food-risk-almaty.git
cd food-risk-almaty
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
make update                      # сырые данные → модель → model/artifact.json
make serve                       # открыть http://localhost:8000/site/

Последняя строка make update начинается с «OK: model/artifact.json» и показывает прогноз на январь–апрель.

3. Что делает каждый шаг

СкриптЧто делаетРезультат
src/prepare.pyчитает выгрузки БНС, FAO, НБК; проверяет фильтры и датыdata/processed/monthly.csv
src/explore.pyсезонность, STL, сезоны по годам, товарыграфики 01–05, eda_summary.csv
src/stationarity.pyADF, KPSS, ACF/PACFstationarity_tests.csv
src/backtest.pyбенчмарки, rolling origin, тест на утечкуbacktest_*.csv
src/backtest_models.pyмодели против бенчмарков, решения в прошломmodel_backtest_*.csv
src/diagnostics.pyLjung–Box и др., выбор модели по правилуdiagnostics.csv
src/export_artifact.pyсобирает всё, что показывает сайтmodel/artifact.json

Сайт ничего не считает сам: он только читает model/artifact.json. Слайдер повторяет формулу модели с коэффициентами из артефакта.

4. Как обновить, когда вышли новые данные

  1. Скачать новые файлы из «Талдау» с тем же фильтром («к предыдущему периоду», помесячно) и положить в data/raw/ рядом со старыми (старые не редактировать).
  2. Записать их в ledger/evidence_ledger.csv.
  3. make update → проверить последнюю строку → закоммитить.
